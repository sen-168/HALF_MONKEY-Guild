HALF MONKEY website

START HERE
1) Unzip the whole folder.
2) Open the HALF_MONKEY folder in VS Code.
3) Run index.html with VS Code Live Server, or deploy the entire folder to Netlify.
4) index.html redirects to Home.html (landing page).
5) From Home.html, enter the guild page. The main guild page is HALF_MONKEY_calendar_page_added.html.

IMPORTANT
- Keep the assets/ and images/ folders and all HTML files together. Do not rename image/audio/video files unless you also update their paths.
- Login status is stored in localStorage and is shared by pages on the same origin (same domain/protocol). The news page can log the member out too.
- Calendar events, posts, comments, and leave requests are stored in this browser only. They are not synchronized between devices or different browsers.
- This is a front-end demo. Member passwords and the admin password are visible in page source; do not use it as a secure production authentication system without a backend.
